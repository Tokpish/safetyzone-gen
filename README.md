# SafetyZone Gen

Статический веб-прототип для построения зоны безопасности вокруг загруженного чертежа.

## Возможности

- Загрузка PNG/JPG через кнопку, drag-and-drop или вставку из буфера обмена `Ctrl+V`.
- Автоматический красный контур зоны безопасности вокруг темных линий изображения.
- Регулировка радиуса, отступов по сторонам, толщины, сглаживания, чувствительности, прозрачности и цвета.
- Ручные замеры радиуса с редактируемой подписью, единицами измерения и цветом.
- Перетаскивание точек замера или всей линии.
- Экспорт результата в PNG.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub.
2. Загрузите файлы `index.html`, `styles.css`, `app.js` и `README.md` в корень репозитория.
3. Откройте `Settings -> Pages`.
4. В `Build and deployment` выберите `Deploy from a branch`.
5. Выберите ветку `main` и папку `/root`.
6. Откройте ссылку GitHub Pages после завершения публикации.

Приложению не нужен сервер и не нужны npm-зависимости.
